# Security policy

Please report suspected vulnerabilities privately. Do not open a public issue for a vulnerability that could expose credentials, private course material, local vault data, or Canvas access.

Send a concise report through [GitHub private vulnerability reporting](https://github.com/davidjoshlee/school-agent-public/security/advisories/new). Include affected version or commit, reproduction steps using synthetic data, impact, and any suggested mitigation.

Do not send access tokens, `.env` files, `school.config.json`, real course work, student information, or other confidential material. We will acknowledge reports when we can, investigate, and coordinate a fix before public disclosure where appropriate.

Scope includes the CLI, configuration handling, local storage, Canvas read-only boundary, and AI Gateway integration. Questions about a school’s academic-integrity policy should go to that school or course staff.
